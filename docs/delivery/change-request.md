# Change request

Use this for anything outside the signed scope: things `scripts/scope-check.ts` flags before the proposal, and anything the clinic asks for during or after the build. Send it before doing the work; start only when the clinic replies "approved" in writing (email or the support channel is fine).

Pricing (spec §3 and §7):
- Work another package covers: offer that package at its price list price.
- The voice agent: + USD 1,000 on Package A.
- Extra lead sources beyond three (Package B): + USD 500 each.
- Anything else: USD 90 an hour, quoted as a fixed number of hours. Prefer suggesting a bigger care plan when the client will keep asking for changes.
- Never included (website design, apps, ads, SEO, content, bank or payroll access): say no, and refer them on if you know someone.
