# Outbound messages (the 20-a-day routine)

From spec §9. Personalise the first line every time; a message that could be sent to any clinic gets no replies. Track each one in the pipeline sheet (spec §6.1): prospect, contacted, replied, discovery done, proposal sent, won or lost.

**Before you send:** check you're allowed to. LinkedIn messages are fine. Cold email to businesses is allowed in Australia only where the address is published for business enquiries and the message is relevant to the business (Spam Act "inferred consent"). Always include who you are and an easy way to opt out, and never use bought lists of personal emails. UK and US rules differ (PECR, CAN-SPAM); read `docs/spec.md` §8 before emailing there.

## Daily routine (about 45 minutes)

1. Add 20 clinics from Google Maps to the sheet: name, owner or practice manager, website, one thing you noticed.
2. Check each website for the gap you'll mention: no online booking, no after-hours option, a contact form only, a phone number only.
3. Send the connection note or first email. Reply to anyone who answered yesterday.
4. For each reply, record a 60-second Loom showing their own website's gap, then the demo clinic answering the same question.

## LinkedIn connection note (under 300 characters)

> Hi {Name}, I build AI front desks for Australian dental clinics. I noticed {Clinic} has {no after-hours booking option / only a phone number} on the site. Happy to show how a clinic like yours handles that in a 60-second video, if useful.

## First email

**Subject:** After-hours bookings for {Clinic}

> Hi {Name},
>
> I looked at {Clinic}'s website: patients can {only call during opening hours / fill in a form and wait}. When someone messages at 9 pm, they usually book wherever answers first.
>
> We set up an assistant that answers WhatsApp, SMS and website chat for clinics, books into your calendar and texts back missed calls. It's live in 14 days for a fixed price.
>
> Worth a 20-minute call? Here's the demo clinic to try first: {website link}.
>
> {Your name}, Nuvadesk
> {One line on how to opt out: "Not relevant? Reply 'no thanks' and I won't email again."}

## Follow-up (day 4): the Loom, nothing else

> Hi {Name}, I recorded 60 seconds on {Clinic}'s enquiry gap and how the assistant would handle it: {Loom link}

## Last follow-up (day 10)

> Hi {Name}, last note from me. If after-hours enquiries aren't a problem for {Clinic}, no worries at all. If they are, the demo is here any time: {website link}.

## When they reply

- Interested: send the booking link (Cal.com) for a 20-minute call. Run it with `discovery-call.md`.
- "How much?": "Setup is a fixed USD 2,500, plus a care plan from USD 300 a month. Happy to show you what's included on a 20-minute call."
- "Not now": thank them, set "re-contact in 90 days" in the sheet (spec §6.1).
- "Stop": remove them from every list the same day.

**Measure weekly** (spec §9): messages sent, reply rate (aim 8%+), calls booked (aim 25% of replies), proposals, close rate (aim 25%+).
